# Daily Tarot for Raycast

Pull your daily tarot card, draw random cards, cast three-card spreads, and get yes/no readings — all from Raycast.

Powered by **[Deckaura](https://deckaura.com)** — free tarot and astrology platform.

## Commands

- **Daily Tarot Card** — Today's card with upright, reversed, love, and career meanings
- **Random Tarot Draw** — Instantly draw a random card
- **Three-Card Spread** — Past / Present / Future reading
- **Yes or No Reading** — Ask a question, get a card-based verdict

## Install

```bash
# From Raycast Store
# Cmd+Space → "Store" → Search "Daily Tarot"
```

Or clone and develop locally:

```bash
git clone https://github.com/gokimedia/raycast-daily-tarot
cd raycast-daily-tarot
npm install
npm run dev
```
